# cumcm-step-review｜数学建模国赛·竞赛级结果优先版

面向全国大学生数学建模竞赛（CUMCM）的**计算优先、结果可复现、结果包交接**工作流，兼容支持 Agent Skills 规范的 Agent。

## 定位

本技能首先解决“题目是否做出来、结果是否真实、算法是否适配、结论是否可复现”，然后把冻结结果整理为论文手可直接使用的结果包。只有用户明确要求时才支持 LaTeX 整合。

核心闭环：

```text
题目拆解 → 数据预检 → 优秀论文与方法检索 → 高质量候选排序 → 主方案优先试跑 → 全量计算
→ 题型匹配验证 → 必要时改进/降级 → 冻结结果 → 结果包交接
```

## 三个审核节点

默认只在以下节点停下来向用户确认：

1. 整体路线：题意、数据、任务表和算法路线；
2. 关键结果：所有子问真实输出、验证指标和主要结论；
3. 结果交接：复现、跨问一致性、关键数字与图表冻结。

用户明确要求时才改为逐节审核。

## 主要特性

- **精准选型**：开局即提出竞赛级主方案、强备选和审计基线；主方案由题目结构与证据决定，不从极简路线机械升级。
- **结果优先**：主方案优先实际运行，以一致口径对照验证算法优势；未运行或未收敛的数字绝不进入论文。
- **运行兜底**：小规模 smoke test、时间/内存估计、随机种子、检查点、最佳可行解和失败降级，避免复杂算法卡死整道题。
- **题型匹配验证**：按预测、优化、评价、仿真、统计、聚类等题型选择验证方式。
- **适度复杂**：不因追求轻量牺牲适配度，也不堆叠复杂模型；只保留能改善结果、可信度或机制解释且赛时可跑通的复杂性。
- **优秀论文借鉴**：保留 `references/优秀论文写法指南.md`、`优秀论文语料分析报告.md` 和摘要写作模块，按章节按需读取，借鉴结构、证据组织和表达方式，不照抄、不把统计偏好当官方规则。
- **论文按需**：默认不承担排版；用户明确要求论文整合时只处理 LaTeX，并保持代码、数据、结果和图表可追溯绑定。
- **AI 合规留痕**：保留真实的 `ai_usage_log.md`；当届规则要求时按 LaTeX/PDF 流程生成 AI 使用详情。

## 目录结构

```text
SKILL.md                   技能入口
references/                阶段流程、模型选型、优秀论文写法与语料、摘要、规范、AI 留痕
scripts/                   数据剖析、图表审计、论文门禁、复现清单
 tools/                    LaTeX / PDF / Excel / 论文搜索 / drawio 工具链
assets/                    算法说明、配色和 LaTeX 构建基线
agents/                    界面调度配置
```

## 使用

将题目原文、附件和已有代码放入题目项目目录，然后对 Agent 说：

> 使用 `$cumcm-step-review` 完成这道国赛题。先结合题目结构、历年优秀论文和必要检索提出 2–4 个高质量候选，明确竞赛级主方案、强备选与审计基线。主方案优先小规模试跑后进行全量计算，用公平对照证明优势，并准备可立即切换的降级方案。最后交付可复现结果包，暂不处理论文排版。

如果只需要做题和计算，可以补充：

> 暂不写论文，先完成数据处理、逐问建模、真实计算、验证和结果文件。

## 交付物

根据用户需求生成：

- 可运行代码、数据处理结果、结果表、日志和复现清单；
- `results/` 下的冻结结果与指标；
- 用户明确要求时生成 `完整论文-LaTeX/` 及由其真实编译得到的 PDF；
- 需要且符合当届规则时的 AI 使用记录和 `AI工具使用详情.pdf`。

所有产物写入题目项目目录；技能目录只读。
